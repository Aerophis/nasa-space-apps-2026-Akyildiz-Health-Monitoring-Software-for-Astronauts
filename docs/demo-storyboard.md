# AstroCare AI — 30-second English demo storyboard

Prepared: 15 November 2026. **Recording plan only; no video has been produced.**

## Recording setup

- Use the accepted interface without redesign. Run the prepared local application
  in English and verify that both workspaces load before recording.
- Start with **Health dashboard → Generated demo**, the latest demo date, and all
  three health metrics selected. Use a desktop viewport and readable browser zoom.
- Prepare a second local browser tab on **NASA Research Explorer**, participant
  **C002**, analyte **Creatinine**. Both tabs use the same local application, not a
  public deployment. Actual files must pass integrity checks before recording.
- Use screen cuts between existing states to keep the total at 30 seconds. Do not
  fabricate UI, measurements, verification badges, or successful saves.
- Keep the synthetic-data notice and research-only label visible where relevant.
  Do not use NASA logos or protected third-party visuals.

## Recording safeguards and fallback

If source files are unavailable or invalid, do not record a verified badge or
substitute demo values in the research view. Prepare the reviewed snapshots first
or show the actual error state and revise the planned narration honestly. Manual
entry is working but omitted from this short cut to protect time; a longer live
demo may use invented records only. Do not claim that the storyboard itself is a
completed video, a public deployment, or a submission.
